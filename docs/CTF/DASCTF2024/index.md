## 准备本地资料

相对于可以联网，除去不能用 AI 外我们也无法获取到一些工具/知识点讲解；由于比赛时间还是挺长的~~（如果不会写就可以开摆了）~~如果基础不是那么扎实，准备一些知识点的教程现场学还是可以的，一般而言有两种：

- PDF教程
- 网页博客

有经验的师傅肯定知道，PDF 上的内容很少能被搜索到，而且又臭又长往往不太愿看；网页才是平时解题时看的更多的东西，其保存方式往往是

- `ctrl/command + s` ，下载 html 文件以及附件
	- 直接点开往往渲染的不那么美观；使用 vsc 的 live server 插件或许是一个更稳定的方式。
- 有时上述方法还是会有一些乱码，这个时候直接浏览器截屏或许一技解君愁：
	- 按下 `F12` 调出开发者工具
	- 按下 `ctrl/command + shift + p` 打开 `运行`
	- 输入 `截屏` 或 `capture` ，选择你需要的（一般使用截取完整尺寸即可）
