> [!extra] 下面是其他待办项目

- 浏览器：对于我个人而言，使用电脑的 50%以上时间在浏览器中；主流的 pc 端浏览器包括但不限为以下四种：
	- [Chrome](https://www.google.com/chrome/)：性能优越，扩展最丰富，主流网站兼容最好，但相对内存占用更高，适合追求**速度与生态**[^1]的用户
	- Edge：兼容性强，**内存优化相对较好**
	- Firefox：安全隐私优先，功能稳健，适合重视**隐私和安全**的开发者和用户
	- Safari：macOS 和 iOS 生态下性能最佳，隐私保护优秀，但跨平台能力弱，更适合 **Apple 设备**用户
		- 我比较喜欢其“工作区”形式的设计，可以切换任务的同时不会打开多个页面
	- 参考：
		- [PC Browsers Compared: Chrome, Edge, Firefox](https://devv.ai/search?threadId=ekqf4uwc2ha8)
		- [Which Browser Is Best?](https://www.pcmag.com/picks/chrome-edge-firefox-opera-or-safari-which-browser-is-best)
- [visual studio code](https://code.visualstudio.com/)：此处主要是那些通用的插件，对于 python、c++等相关插件不会提及
	- [copilot](https://github.com/features/copilot)
	- [codesnap](https://blog.csdn.net/qq_51165234/article/details/126201838)
	    - 代码截图
	- [background](https://blog.csdn.net/weixin_44112083/article/details/125223060)
	    - 背景添加
	- [VSCode配置verilog环境(代码提示+自动例化+格式化)](https://blog.csdn.net/SEU_wzx/article/details/126804348)
- [everything](https://www.voidtools.com/zh-cn/downloads/)
    - 快速搜寻各种文件样例，支持正则表达式匹配；
    - 使用较少安装便携版即可。
- [uni-api](https://github.com/yym68686/uni-api)
	- 基于模型 ID 将不同服务商的 api 整合
	- [uni-api-status](https://github.com/melosbot/uni-api-status) 前端
	- [uni-api 配置生成器](https://uni-api-config-generator.vercel.app/)

[^1]: 生态的前提是有一个谷歌账号。
