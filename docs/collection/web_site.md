- [pandoc](https://pandoc.org/)

- 英文论文翻译
	- [ChatPaper](https://github.com/kaixindelele/ChatPaper)
		- 可以免费使用[学术版GPT 网页非盈利版](https://academic.chatwithpaper.org/)
			- 针对 arXiv 比较厉害的一个功能是，根据论文**摘要链接**，获取 tex 源码，对其翻译后再编译，所以翻译后看起来比直接翻译 pdf 好很多
		- [示例教程](https://zhuanlan.zhihu.com/p/692337102)
		- [zh_Traced ICSE 24](../static/zh_Traced%20ICSE%2024.pdf){:download="zh_Traced ICSE 24"} 是一个成功例子
	- [有道在线翻译](https://fanyi.youdao.com/#/AITranslate)
		- 有道的翻译也不错，其 [arXiv 论文翻译](https://fanyi.youdao.com/trans/#/home)排版效果也挺好
	- [沉浸式翻译](https://chromewebstore.google.com/detail/immersive-translate-trans/bpoadfkcbjbfhfodiogcnhhhpibjhbnh)
		- 在阅读 Html 版本时可以搭配使用
		- Tips:（以 [https://arxiv.org/abs/1502.03808](https://arxiv.org/abs/1502.03808) 为例）​
		      - 替换「x」为「5」跳转到 HTML 版本阅读​，搭配沉浸式翻译使用：[https://ar5iv.org/abs/1502.03808](https://ar5iv.org/abs/1502.03808)
		      - 替换「v」为「w」跳转到 txyz 处理​：[https://arxiw.org/abs/1502.03808](https://arxiw.org/abs/1502.03808)
	- [paf2zh](https://pdf2zh.com/)

### X 床

> [!extra] 取图“床”之意，表示能够暂时借助以在线存储/传播一些东西。

- [imgbb](https://imgbb.com/) or [smms](https://sm.ms/)
    - 免费图床，敏感图片就最好自己搭建图床了。
- [godbolt](https://godbolt.org/)
    - 免费“代码床”，因为右上角 **share** 可以获得 <u>保留代码</u> 的链接；
    - 在线编辑器，可以同时切换不同版本编译器运行代码；
    - 支持展示编译内容，[例如](https://godbolt.org/z/nK8eqxc71)。
	- 其他“知名”代码床：[Github gist](https://gist.github.com/) or [LeetCode/playground](https://leetcode.com/playground/) or [One Compiler](https://onecompiler.com/)
